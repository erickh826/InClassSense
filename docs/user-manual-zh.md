## 簡介

InClassSense 是一個多模態 AI 觀察與評估平台，專為教育工作者及面試評核設計。系統透過裝置上的鏡頭與麥克風，即時分析受試者的：

- **專注度** — 透過臉部朝向偵測是否注視螢幕
- **情緒反應** — 即時辨識表情（開心、困惑、驚訝、平靜、未偵測到臉部）
- **語言表達** — 語音轉文字，記錄完整對話紀錄

所有影像分析均在您的設備端本地完成，**影像絕不會上傳到伺服器**。觀察結束後，系統將統計數據與對話紀錄傳送給 AI 大語言模型，生成一份結構化的評估報告。

## 系統需求

| 項目 | 最低需求 |
|------|---------|
| 瀏覽器 | Chrome 或 Edge（桌面版或 Android）— **推薦** |
| | Safari（iPad）— 鏡頭與情緒偵測正常，語音辨識支援有限 |
| | Firefox — 不支援語音辨識，僅能使用視覺分析 |
| 硬體 | 前置或後置鏡頭、麥克風 |

## 開始使用

1. 用瀏覽器打開 InClassSense 網址
2. 首頁會顯示三個觀察模式的選擇卡片
3. 點擊您想使用的模式即可進入觀察介面

## 觀察模式

### 🧒 幼兒發展觀察

**適用場景：** 幼兒園課堂活動、一對一互動教學

**功能：**
- 記錄幼兒的語言表達（中文）
- 偵測專注度與情緒變化
- 生成兒童發展觀察報告，涵蓋語言溝通能力、情緒投入度、建議觀察重點

**預設鏡頭：** 後置鏡頭（由老師拍攝面向幼兒）

### 🗣️ 英語口語練習

**適用場景：** IELTS Speaking 模擬練習

**功能：**
- 記錄英語口語回答（英文語音辨識）
- 可輸入題目（支援 Part 1 / Part 2 / Part 3 題型）
- 偵測練習期間的自信度與專注力
- 生成 IELTS Speaking 評分報告，包含四項評分標準的分數與改進建議

**預設鏡頭：** 前置鏡頭（自拍模式）

**額外輸入：** 題目（例如：Describe a place you enjoy visiting.）

### 🎤 面試評核

**適用場景：** 幼稚園入學面試、大學實習面試

**功能：**
- 支援兩種面試模式切換：
  - 👶 **幼稚園入學** — 評估語言發展、社交情緒、學習準備度（中文報告）
  - 🎓 **大學實習 Intern** — 評估溝通能力、批判思維、專業度（英文報告）
- 可輸入面試問題
- 偵測面試者的情緒穩定性與專注力
- 生成面試評核報告

**預設鏡頭：** 前置鏡頭

**額外輸入：** 面試問題

## 操作流程

### 步驟一：選擇模式

在首頁點擊您想使用的觀察模式卡片。

### 步驟二：設定觀察

進入觀察介面後，您會看到以下設定項目：

1. **課程主題 / 面試崗位** — 輸入本次觀察的主題名稱
2. **額外欄位**（部分模式）— 例如題目、面試問題
3. **模式變體切換**（面試模式）— 選擇幼稚園入學或大學實習
4. **鏡頭切換** — 點擊「🤳 前置鏡頭」或「📷 後置鏡頭」切換

### 步驟三：開始觀察

1. 點擊 **「▶ 開始觀察」** 按鈕
2. 系統會請求鏡頭與麥克風權限 — **請允許**
3. 鏡頭畫面會即時顯示，畫面下方顯示即時情緒與注視狀態
4. 螢幕上方會出現綠色隱私標示：「本地 AI 分析中，影像不會離開您的設備」
5. 右側對話紀錄區域會即時顯示語音轉文字結果

### 步驟四：結束觀察

1. 點擊 **「■ 結束觀察」** 按鈕
2. 鏡頭與麥克風會立即關閉
3. 系統自動計算統計數據，並將情緒標註同步到對話紀錄
4. 顯示「正在生成報告…」

### 步驟五：查看報告

- 報告以 Markdown 格式呈現在頁面下方
- 報告內容根據所選模式不同而有所差異
- 如需返回首頁選擇其他模式，點擊頁面頂部的返回按鈕

## 報告說明

### 幼兒發展觀察報告包含：

1. **語言溝通能力評估** — 詞彙量、句型、理解力、表達流暢度
2. **情緒投入度評估** — 專注度、表情時機、遇困難時的情緒反應
3. **建議觀察重點** — 給老師的下次引導方向

### IELTS Speaking 評估報告包含：

1. **整體模擬分數** — 0–9 分（精確至 0.5）
2. **四項評分標準** — 流暢度與連貫性、詞彙資源、語法範圍與準確性、發音
3. **具體引用** — 從對話紀錄中引用的範例
4. **改進建議** — 下次練習的具體方向

### 面試評核報告包含：

- **幼稚園入學版：** 語言發展、社交情緒、學習準備度、整體建議
- **大學實習版：** 溝通能力、批判思維、穩重度、發展潛力、聘用建議

## 隱私保障

| 保障措施 | 說明 |
|---------|------|
| 本地視覺分析 | 所有臉部偵測與情緒辨識在您的設備上進行，使用 Web Worker 技術 |
| 不保存影像 | 系統不會截圖或錄影，僅處理即時的臉部座標數據 |
| 即時關閉鏡頭 | 觀察結束後，鏡頭立即停止運作 |
| 資料清除 | 原始分析數據在統計計算完成後從記憶體中清除 |
| API 金鑰安全 | LLM API 金鑰存放在伺服器端，不會傳送到瀏覽器 |
| 隱私標示 | 鏡頭使用期間，畫面上持續顯示隱私保護提示 |

## 常見問題

### Q: 為什麼語音辨識沒有反應？

- 請確認使用的是 Chrome 或 Edge 瀏覽器
- 請確認已允許麥克風權限
- 請確認裝置麥克風正常運作
- Safari 和 Firefox 對語音辨識的支援有限

### Q: 鏡頭畫面看起來是鏡像的？

使用前置鏡頭時，畫面會自動鏡像顯示（如同自拍），這是正常行為。後置鏡頭則不會鏡像。

### Q: 情緒偵測顯示「👤 臉部未入鏡」？

請確認臉部位於鏡頭畫面範圍內，確保光線充足，避免臉部被遮擋。

### Q: 報告生成失敗？

- 請確認網路連線正常
- 如果持續失敗，可能是 LLM 服務暫時不可用，請稍後再試

### Q: 可以在 iPad 上使用嗎？

可以。建議使用 iPad 上的 Chrome 瀏覽器以獲得最佳體驗。Safari 可使用鏡頭與情緒偵測功能，但語音辨識支援可能不完整。

### Q: 資料會傳送到哪裡？

- **影像/鏡頭數據：** 完全不會離開您的設備
- **語音轉文字結果：** 透過瀏覽器內建的 Web Speech API 處理（各瀏覽器的處理方式不同）
- **統計數據與對話紀錄：** 觀察結束後傳送給 Azure OpenAI 以生成報告
